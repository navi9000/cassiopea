# Запуск проекта локально

Если в редакторе кода подключен встроенный сервер, то достаточно запустить его. Например, если в VSCode настроен live server, то в правом нижнем углу появляется кнопка Go Live. Для запуска проекта достаточно нажать ее.

В качестве альтернативы я добавил простой сервер в файле server.js. Для запуска проекта с помощью него нужно в терминале ввести команду `node server.js`
